## limpet 1.0.0

The first public release, and the first build signed with a Developer ID and notarized by Apple. The 0.80.0 line was inherited from SyncTray; 1.0.0 starts limpet's own version history.

- **Signed and notarized.** The DMG opens without a Gatekeeper warning.
- **Updates in the app.** "Check for Updates…" in the menu uses Sparkle. The update feed is signed and served from this repository's releases.
- **Permissions may be asked again.** The signing identity changed from 0.80.0, so macOS can treat this as a different app and ask again for permissions you already granted, such as Full Disk Access (TCC). Re-grant them if syncs report access errors.
- **Upgrading from 0.80.0.** Replace the app from the DMG, then run `limpet reinstall <id>` for each enabled profile so its watcher runs the new binary.
