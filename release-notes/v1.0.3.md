## limpet 1.0.3

- **Adjustable speed for incremental batches.** A new profile setting, "Batch Requests per Second" (the profile's Advanced section, or `limpet profile set <name> batchRequestsPerSecond <1-64>`), sets how many requests a batch may send to the remote each second. The default goes from a fixed 4 to 16, so a new worktree or a git repack (hundreds or thousands of small files at once) syncs about four times faster. Higher values are faster still, but a long burst at 16 or more can reach the request volume at which MEGA S4 has temporarily blocked uploads; syncing then pauses for a while and resumes on its own, and nothing is lost. A `--tpslimit` in the profile's additional rclone flags overrides the setting.
