## limpet 1.0.2

- **Incremental sync (opt-in).** A new profile setting makes the watcher upload only the files macOS reported as changed, in small batches. Without it, every change compares the whole folder with the remote, which kept rclone busy on large, busy folders. A full comparison still runs when the watcher starts, every 6 hours (or the profile's interval, if longer), on "Sync now", and whenever file events may have been missed. Turn it on with `limpet profile set <name> incrementalSync true`. It is off by default. A profile keeps full syncs, and its log says why, if it syncs remote → local or if its rclone flags or exclude rules change what a batch would sync (for example include rules or `--delete-excluded`).
