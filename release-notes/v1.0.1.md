## limpet 1.0.1

The first update delivered through "Check for Updates…".

- **No red menu for files that change while uploading.** When a file is written to during its upload (a log or an experiment appending results), rclone's checksum check fails. limpet now retries that run 30 seconds later instead of showing "Exit code 1" and sending a failure notification. If the same failure repeats 20 runs in a row, it is shown as an error again, so real transfer corruption is not hidden. `limpet status` shows `last=retrying` meanwhile.
- **Your exclude rules survive setting changes.** Changing any profile setting (in the app or with `limpet profile set`) reinstalls the profile, and that used to reset `<id>-exclude.txt` to the defaults, silently dropping rules you added. The file is now kept, and removed only when the profile is deleted.
